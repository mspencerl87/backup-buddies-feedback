# Backup Buddies — feedback &amp; issue tracker

This repo is just for **bug reports and feature requests** for
[Backup Buddies](https://app.filegarden.net), a peer-to-peer backup app.

The app's actual code lives in a separate, private repo — this one exists
so anyone can file an issue without needing access to that code. There's
no code here on purpose.

## Account, login, password or billing problems

**Don't open an issue for these** — issues here are public, and these
need your account details. Instead:

- Forgot your password? Use [Forgot password?](https://app.filegarden.net/forgot-password.html).
- Anything else: use **Contact support** on your
  [dashboard](https://app.filegarden.net/dashboard.html#support), or if you
  can't log in, email **support@filegarden.net** from your account's email
  address.

## Before filing something new

- Check the [feature status page](https://app.filegarden.net/status.html)
  first — it lists what's available today and what's a known limitation
  or already in progress. Your issue might already be a known, documented
  limitation rather than a bug.
- Search [existing issues](https://github.com/mspencerl87/backup-buddies-feedback/issues)
  to see if someone's already reported it.

## Filing a bug report

Open a [new issue](https://github.com/mspencerl87/backup-buddies-feedback/issues/new/choose)
and pick the "Bug report" template. The more specific you can be (what
you expected, what happened instead, your OS/network setup if relevant),
the faster it can be tracked down.

## Requesting a feature

Open a [new issue](https://github.com/mspencerl87/backup-buddies-feedback/issues/new/choose)
and pick the "Feature request" template. Explain what you're trying to
do and why the current behavior doesn't cover it — that's more useful
than a specific implementation suggestion.

## What happens next

Issues here are reviewed by hand, not automatically triaged. You won't
get access to the private codebase, and not every request will be taken
on, but every issue gets read.
